Docker

Containers • Docker Compose • CI/CD e DevOps

Descrição

Plataforma de containerização para empacotamento, distribuição e execução de aplicações em ambientes isolados, garantindo portabilidade e consistência entre desenvolvimento e produção.

Containers e Imagens

  • Criação de imagens customizadas via Dockerfile com multi-stage build
  • Isolamento completo de processos, rede e sistema de arquivos por container
  • Camadas de imagem com cache inteligente para builds mais rápidos
  • Registro e versionamento de imagens no Docker Hub e registries privados
  • Containers efêmeros e stateless para deploy consistente em qualquer ambiente

Docker Compose e Stacks

  • Orquestração de múltiplos serviços com docker-compose.yml declarativo
  • Definição de redes, volumes e dependências entre serviços
  • Variáveis de ambiente via arquivos .env para configuração por ambiente
  • Escalabilidade horizontal com réplicas de serviços individuais
  • Profiles para subir subconjuntos de serviços conforme necessidade

Redes e Volumes

  • Redes bridge, overlay e host com isolamento e roteamento configurável
  • Volumes nomeados e bind mounts para persistência de dados
  • Comunicação entre containers via DNS interno por nome de serviço
  • Volumes NFS e CIFS para integração com armazenamento externo
  • Drivers de volume customizados para backends de armazenamento avançados

Segurança e Boas Práticas

  • Execução de containers com usuário não-root para reduzir superfície de ataque
  • Secrets do Docker para injeção segura de credenciais em serviços
  • Limitação de recursos de CPU e memória por container
  • Scan de vulnerabilidades em imagens com Docker Scout
  • Política de restart automático para alta disponibilidade dos serviços

Recursos Técnicos do Projeto Docker

  • Host: Docker Engine instalado em LXC privilegiado no Proxmox VE
  • Gestão: Portainer CE para gerenciamento visual de todos os containers
  • Compose: Todos os serviços declarados em docker-compose.yml versionados no GitHub
  • Redes: Bridges dedicadas por stack com isolamento entre serviços
  • Volumes: Dados persistentes em NFS montado no TrueNAS via bind mount
  • Proxy: Nginx Proxy Manager como ponto de entrada único com SSL/TLS
  • Segurança: Containers sem privilégios de root e limitação de recursos por serviço
