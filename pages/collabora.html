Collabora Online

Edição Colaborativa • Office Online • Integração Nextcloud

Descrição

Suite de edição de documentos online self-hosted integrada ao Nextcloud, baseada no motor do LibreOffice, com suporte completo a formatos Microsoft Office e edição colaborativa em tempo real via protocolo WOPI.

Edição de Documentos e Planilhas

  • Edição completa de DOCX, XLSX e PPTX diretamente no navegador
  • Motor baseado no LibreOffice com excelente compatibilidade com formatos ODF
  • Suporte nativo a ODT, ODS, ODP e outros formatos abertos
  • Conversão entre formatos via API WOPI integrada
  • Visualização e edição de PDFs com suporte a anotações

Colaboração em Tempo Real

  • Edição simultânea por múltiplos usuários com sincronização instantânea
  • Controle de revisões com rastreamento de alterações por autor
  • Comentários inline com threads de discussão por trecho
  • Histórico de versões com restauração de qualquer ponto
  • Modo de revisão com aceitar ou rejeitar mudanças individualmente

Integração com Nextcloud

  • Abertura e edição de documentos direto no Nextcloud via app Nextcloud Office
  • Salvamento automático no armazenamento do Nextcloud via WOPI
  • Compartilhamento de documentos para edição com link externo
  • Controle de permissões herdado do Nextcloud por usuário e grupo
  • Visualização de documentos sem necessidade de instalar software local

Segurança e Infraestrutura

  • Deploy via Docker com imagem oficial collabora/code
  • Comunicação criptografada via HTTPS entre Nextcloud e Collabora (CODE)
  • Isolamento de rede com containers em bridge dedicada
  • Autenticação via protocolo WOPI sem necessidade de chave JWT externa
  • Logs de auditoria de acesso e edição de documentos

Recursos Técnicos do Projeto Collabora Online

  • Deploy: Container Docker com imagem oficial collabora/code (Collabora Online Development Edition)
  • Integração: App Nextcloud Office instalado no Nextcloud com URL do CODE configurada
  • Protocolo: WOPI (Web Application Open Platform Interface) para comunicação segura entre Nextcloud e Collabora
  • Rede: Containers em bridge interna, expostos via Nginx Proxy Manager
  • SSL/TLS: Certificado Let's Encrypt gerenciado pelo Nginx Proxy Manager
  • Armazenamento: Volume persistente para configurações e logs do CODE
  • Recursos: 2 vCPU e 4 GB RAM dedicados ao container para edição fluida
  • Formatos: DOCX, XLSX, PPTX, ODT, ODS, ODP e PDF com conversão automática via LibreOffice
Collabora CODE LibreOffice Nextcloud Docker WOPI Nginx SSL/TLS ODF Self-Hosted
Nota: Este projeto implementa o Collabora Online (CODE) integrado ao Nextcloud, oferecendo uma suite de escritório online completa e self-hosted com edição colaborativa em tempo real. Baseado no motor do LibreOffice, garante excelente compatibilidade com formatos ODF e Microsoft Office, com controle absoluto sobre os documentos sem depender de serviços externos como Google Docs ou Office 365.
