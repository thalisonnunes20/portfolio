AdGuard Home

DNS • Bloqueio de Anúncios • Proteção de Rede

Descrição

Servidor DNS self-hosted com bloqueio de anúncios e rastreadores em nível de rede, protegendo todos os dispositivos conectados.

Bloqueio de Anúncios e Rastreadores

  • Bloqueio DNS de anúncios em toda a rede sem instalar extensões
  • Listas de bloqueio atualizadas automaticamente (EasyList, Steven Black, etc.)
  • Filtros customizáveis por domínio, regex e wildcards
  • Bloqueio de rastreadores, telemetria e malware
  • Proteção para smart TVs, IoT e dispositivos móveis

Servidor DNS Avançado

  • Suporte a DNS-over-HTTPS (DoH) e DNS-over-TLS (DoT)
  • DNS-over-QUIC para conexões ainda mais seguras
  • Cache DNS local para respostas mais rápidas
  • Upstream DNS configurável (Cloudflare, Google, Quad9)
  • Reescrita de DNS para domínios internos e split-horizon

Controle e Monitoramento

  • Dashboard em tempo real com estatísticas de consultas
  • Log completo de todas as requisições DNS por cliente
  • Controle parental com agendamento por horário
  • Listas de permissão e bloqueio por cliente ou grupo
  • Relatórios detalhados de domínios mais requisitados

Integração e Alta Disponibilidade

  • Deploy em Docker com configuração persistente
  • Integração com DHCP para identificação automática de clientes
  • Configuração de redundância com dois servidores AdGuard
  • API REST para automação e integração com outros sistemas
  • Suporte a IPv4 e IPv6 em toda a stack

Recursos Técnicos do Projeto AdGuard Home

  • Versão: AdGuard Home latest (Docker)
  • Deploy: Container Docker com volumes persistentes para config e dados
  • DNS Upstream: Cloudflare DoH (1.1.1.1) e Quad9 (9.9.9.9) com fallback
  • Protocolos: DNS-over-HTTPS e DNS-over-TLS habilitados
  • Listas: EasyList, Steven Black, AdGuard DNS filter e listas customizadas
  • Clientes: Identificação automática via integração com DHCP
  • Redundância: Dois servidores AdGuard em hosts distintos
