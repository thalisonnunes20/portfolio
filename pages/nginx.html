Nginx Proxy Manager

Proxy Reverso • SSL/TLS • Gerenciamento Web

Descrição

Solução de proxy reverso com interface web para gerenciamento simplificado de domínios e certificados.

Proxy Reverso e Load Balancing

  • Encaminhamento de tráfego para serviços internos
  • Load balancing entre múltiplos servidores back-end
  • Health checks para monitoramento de disponibilidade
  • Cache de conteúdo estático para performance
  • Rate limiting para proteção contra DDoS

Gerenciamento de Certificados SSL

  • Obtenção automática de certificados Let's Encrypt
  • Renovação automática de certificados
  • Suporte a wildcard certificates
  • Força HTTPS com redirect automático
  • HTTP/2 e HTTP/3 (QUIC) habilitados

Interface Web Intuitiva

  • Dashboard com status de todos os proxies
  • CRUD completo de host redirections
  • Editor de configurações Nginx avançado
  • Logs de acesso em tempo real
  • Autenticação básica para acesso restrito

Segurança e Performance

  • Web Application Firewall (ModSecurity)
  • Proteção contra bots e scanners
  • Gzip e Brotli compression
  • Configuração otimizada para performance
  • Backup automático de configurações

Recursos Técnicos do Projeto

  • Plataforma: Nginx Proxy Manager 2.11
  • Container: Docker Compose com 3 serviços
  • Banco de Dados: MariaDB para armazenamento
  • SSL: Let's Encrypt com auto-renewal
  • Proxy: Nginx 1.24 com configurações customizadas
  • Monitoramento: Logs centralizados + Grafana
  • Backup: Scripts para backup de configurações
