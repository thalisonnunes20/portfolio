pfSense

Firewall • VPN • Segurança de Rede

Descrição

Firewall empresarial baseado em FreeBSD com recursos avançados de segurança e rede.

Firewall e Filtragem

  • Stateful packet inspection com regras granulares
  • NAT (Network Address Translation) e PAT
  • Filtro de conteúdo por categoria (SquidGuard)
  • Limitação de banda (Traffic Shaper)
  • IDS/IPS com Suricata ou Snort

VPN e Acesso Remoto

  • OpenVPN para acesso remoto seguro
  • WireGuard para VPN moderna de alta performance
  • IPsec para site-to-site corporativo
  • L2TP/IPsec para clientes móveis
  • Multi-factor authentication (TOTP, RADIUS)

Segmentação e VLANs

  • Isolamento de rede por departamentos
  • VLANs para guest, IoT e servidores
  • Firewall rules entre VLANs
  • Captive portal para Wi-Fi público
  • DHCP server por VLAN

Monitoramento e Logs

  • Dashboard em tempo real do tráfego
  • Logs detalhados de conexões bloqueadas
  • Reporting com gráficos e estatísticas
  • Integração com syslog externo
  • Alertas por email para eventos críticos

Recursos Técnicos do Projeto pfSense

  • Sistema Operacional: pfSense 2.8.1
  • Hardware: Protectli Vault ou PC Engines APU
  • Interfaces: 2 portas Gigabit Ethernet
  • VPN: WireGuard Configurado
  • IDS/IPS: Suricata com regras OISF/Talos
  • Monitoramento: NetFlow exporter + Grafana
  • Backup: Configuração automática para cloud
