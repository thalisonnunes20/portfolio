Descrição

Sistema de armazenamento empresarial baseado em ZFS com recursos avançados de proteção de dados.

Sistema de Arquivos ZFS

  • Copy-on-write com integridade de dados end-to-end
  • RAID-Z (Z1, Z2, Z3) com parity ajustável
  • Snapshots instantâneos e espaço eficiente
  • Deduplicação e compressão transparente
  • Scrubbing automático para detecção de erros

Protocolos de Compartilhamento

  • SMB/CIFS para ambientes Windows
  • NFS v3/v4 para sistemas Unix/Linux
  • iSCSI para virtualização e bancos de dados
  • AFP para clientes Apple legacy
  • FTP/FTPS e SFTP para transferências

Backup e Replicação

  • Replicação ZFS para outro TrueNAS
  • Integração com cloud (AWS S3, Backblaze B2)
  • Snapshots periódicos e retenção
  • Rsync para backup incremental
  • VM backup com VSS para Windows

Monitoramento e Alerta

  • Dashboard com health status dos discos
  • SMART monitoring e predição de falhas
  • Alertas por email, Slack ou Telegram
  • Reporting de uso de espaço e performance
  • Integração com Grafana para métricas

Recursos Técnicos do Projeto TrueNAS

  • Plataforma: TrueNAS Scale 25.04.2.6
  • Hardware: 8GB Ram DDR4
  • Storage: 1x6TB (Sem Espelho)
  • Rede: Porta 1G
  • Protocolos: SMB, NFS, iSCSI, SFTP
  • Recursos ZFS: Snapshots, compressão, deduplicação
  • Apps: Nextcloud, Jellyfin, containers Docker
