Homarr

Dashboard • Self-Hosted • Docker • Homelab

Descrição

Dashboard moderno e altamente customizável para homelab, com integração nativa a serviços self-hosted, widgets interativos e visão centralizada de toda a infraestrutura em uma única interface elegante.

Interface e Customização

  • Layout de grade totalmente personalizável com drag-and-drop de widgets e ícones
  • Suporte a múltiplos temas e modo escuro nativo com paletas de cores configuráveis
  • Criação de seções e categorias para organizar serviços por função ou ambiente
  • Ícones automáticos via integração com bibliotecas de logos de serviços populares
  • Interface responsiva com adaptação automática para dispositivos móveis e tablets

Integração com Serviços

  • Integração nativa com Jellyfin, Sonarr, Radarr, qBittorrent e dezenas de outros serviços
  • Widgets de status em tempo real mostrando uso de CPU, memória e disco dos hosts
  • Widget de DNS com estatísticas do AdGuard Home ou Pi-hole diretamente no dashboard
  • Integração com Proxmox VE para exibição de status de VMs e containers LXC
  • Suporte a calendários, RSS feeds e previsão do tempo com localização configurável

Gerenciamento e Acesso

  • Sistema de autenticação com múltiplos usuários e controle de permissões por board
  • Múltiplos boards configuráveis para diferentes contextos (pessoal, infra, mídia)
  • Acesso seguro via Nginx Proxy Manager com SSL/TLS e autenticação integrada
  • Importação e exportação de configurações em formato JSON para backup e migração
  • API REST para automação e integração com outros serviços da stack

Deploy e Infraestrutura

  • Deploy via Docker Compose com imagem oficial e configuração mínima
  • Persistência de configurações via volume bind mount para portabilidade total
  • Executado em LXC no Proxmox VE com recursos mínimos de CPU e memória
  • Atualização automática de containers via Watchtower integrado ao workflow
  • Suporte a variáveis de ambiente para configuração segura de credenciais

Recursos Técnicos do Projeto Homarr

  • Host: Container Docker em LXC privilegiado no Proxmox VE
  • Imagem: ghcr.io/ajnart/homarr com tag latest via Docker Compose
  • Persistência: Volume bind mount para /app/data/configs e /app/public/icons
  • Proxy: Nginx Proxy Manager com SSL/TLS via Let's Encrypt
  • Integrações ativas: AdGuard Home, Proxmox VE, Jellyfin e Portainer
  • Autenticação: Usuários locais com controle de acesso por board
  • Atualizações: Watchtower monitorando a imagem para pull automático

Nota: O Homarr centraliza o acesso a todos os serviços self-hosted do homelab em um dashboard único e elegante, eliminando a necessidade de memorizar portas e IPs. Com integração direta ao Proxmox VE, AdGuard Home e Jellyfin, fornece visibilidade em tempo real do estado de toda a infraestrutura, demonstrando habilidades em orquestração de serviços, Docker e administração de ambientes self-hosted.
