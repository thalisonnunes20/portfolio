WireGuard

VPN Moderna • Alta Performance • Criptografia

Descrição

Implementação de VPN WireGuard para acesso seguro remoto com performance superior e configuração simplificada.

Performance e Eficiência

  • Kernel-space implementation para throughput máximo
  • Latência mínima comparada com OpenVPN/IPsec
  • Consumo mínimo de CPU mesmo em links de alta velocidade
  • Conexões persistentes com roaming suportado
  • NAT traversal automático via UDP hole punching

Segurança Moderna

  • Criptografia ChaCha20Poly1305
  • Curvas elípticas Curve25519 para troca de chaves
  • Perfect Forward Secrecy com chaves efêmeras
  • Minimal attack surface - apenas 4,000 linhas de código
  • Formal verification do protocolo

Gerenciamento via WG-Easy

  • Interface web para gerenciamento de clientes
  • QR Code generation para configuração móvel
  • Statistics dashboard com tráfego por cliente
  • API REST para automação
  • Backup/restore de configurações

Configuração e Clientes

  • Clientes oficiais para Windows, macOS, Linux
  • Apps móveis para iOS e Android
  • Configuração via arquivo único ou QR Code
  • Suporte a IPv4 e IPv6 dual stack
  • Split tunneling e DNS configuration

Recursos Técnicos do Projeto WireGuard

  • Plataforma: WG-Easy (interface web para WireGuard)
  • Container: Docker com WireGuard + interface web
  • Sistema: TrueNas 25.04.2.6
  • Porta VPN: UDP 51820
  • Porta Admin: 51821 para interface web
  • Clientes: Suporte para Windows, macOS, Linux, iOS, Android
  • Monitoramento: Dashboard com estatísticas em tempo real
  • Backup: Scripts automáticos de backup de configuração
