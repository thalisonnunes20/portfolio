Immich

Fotos • Vídeos • Backup Self-Hosted com IA

Descrição

Solução self-hosted de backup e gerenciamento de fotos e vídeos com reconhecimento facial por IA, alternativa ao Google Photos com privacidade total.

Backup e Sincronização

  • Backup automático de fotos e vídeos via app mobile (iOS e Android)
  • Sincronização em tempo real ao conectar na rede Wi-Fi
  • Suporte a uploads em background sem abrir o aplicativo
  • Preservação de metadados EXIF, localização e data original
  • Deduplicação automática para evitar arquivos duplicados

Inteligência Artificial

  • Reconhecimento facial automático com agrupamento por pessoa
  • Classificação de objetos, animais, cenas e atividades por IA
  • Busca semântica por texto (ex: "praia com cachorro")
  • Geração automática de memórias e álbuns por data e local
  • Machine learning local sem enviar dados para servidores externos

Organização e Compartilhamento

  • Álbuns manuais e automáticos com compartilhamento por link
  • Linha do tempo cronológica com visualização por mapa
  • Suporte a múltiplos usuários com quotas individuais
  • Favoritos, arquivamento e lixeira com retenção configurável
  • Visualizador de RAW, HEIC, Live Photos e vídeos

Infraestrutura e Armazenamento

  • Deploy via Docker Compose com múltiplos serviços orquestrados
  • Integração com armazenamento externo via NFS e S3-compatible
  • Banco de dados PostgreSQL com pgvector para busca por similaridade
  • Transcodificação de vídeo com aceleração por hardware (NVENC, VAAPI)
  • API REST e suporte ao protocolo importe de bibliotecas externas

Recursos Técnicos do Projeto Immich

  • Deploy: Docker Compose com containers server, microservices, ML e Redis
  • Banco de dados: PostgreSQL com extensão pgvector para busca vetorial
  • Armazenamento: Volume NFS montado no TrueNAS para persistência
  • Machine Learning: Modelo local CLIP para busca semântica e reconhecimento facial
  • Transcodificação: Aceleração por hardware via VAAPI (Intel Quick Sync)
  • Acesso: Nginx Proxy Manager com SSL/TLS e domínio externo
  • Backup: Fotos originais replicadas no TrueNAS via ZFS snapshot

Nota: Este projeto implementa o Immich como substituto self-hosted do Google Photos, com backup automático via app mobile, reconhecimento facial por IA local, busca semântica e armazenamento integrado ao TrueNAS, garantindo privacidade total dos dados sem depender de serviços na nuvem.
