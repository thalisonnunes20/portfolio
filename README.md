# Portfolio

Portfolio pessoal desenvolvido para apresentar meus projetos, habilidades e experiências na área de tecnologia e desenvolvimento.

## Sobre o Projeto

Este portfolio foi criado com foco em:

* Design moderno e responsivo
* Boa experiência do usuário
* Performance e organização
* Apresentação profissional dos projetos

O objetivo é centralizar meus trabalhos, experiências e formas de contato em um único lugar.

---

## Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript
* Responsividade Mobile
* Animações e efeitos visuais

---

## Funcionalidades

* Interface moderna
* Layout responsivo
* Sessão de projetos
* Informações profissionais
* Links para contato e redes sociais
